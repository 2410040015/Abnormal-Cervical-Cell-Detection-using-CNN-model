# Abnormal-Cervical-Cell-Detection-using-CNN-model
>>>Project Workflow

The workflow of this project begins with collecting cervical cell images from the SIPaKMeD dataset. The images are then preprocessed by resizing, normalizing, and labeling them for training purposes. After preprocessing, the dataset is divided into training and testing sets. A Convolutional Neural Network (CNN) model is built using TensorFlow and Keras in Python within VS Code. The CNN learns important image features through convolution, pooling, and dense layers during the training process. Once the model is trained, it is tested using unseen cervical cell images to predict whether the cells are normal or abnormal. Finally, the model performance is evaluated based on prediction accuracy and classification results.

>>>Conclusion
This project demonstrates how deep learning and CNN models can be used in the medical field for abnormal cervical cell detection. Using TensorFlow and Keras, the system successfully classifies cervical cell images based on microscopic image features. The project provides a simple and effective approach for medical image classification using artificial intelligence
